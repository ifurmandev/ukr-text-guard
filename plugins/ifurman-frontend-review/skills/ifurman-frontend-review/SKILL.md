# ifurman.dev — рев'ю фронтенду

Проєкт: Astro 5.18 + Tailwind 4, CSS-first конфіг у `src/styles/global.css`,
`tailwind.config.*` немає. Локально `G:\IFurman\Site`, `npm run dev :4321`.
Astro 7 НЕ оновлювати.

Цей скіл — не рекомендації. Це правила, куплені помилками. Порушення кожного
з них уже коштувало сесії переробок.

## 0. Протокол роботи (найважливіше)

**Коміт тільки з явного слова Ігоря.** Не «здається, він погодився», не
«він сказав ок на попереднє». Явне слово на цю конкретну зміну.

Порядок: `git status` → `git diff` → **показати diff текстом у відповіді**
→ чекати слова → коміт.

**Diff треба вставити в відповідь текстом, у блоці ```diff.** Фраза
«diff показано вище» без самого тексту — це не звіт. Ця помилка
повторювалась шість разів за одну сесію.

Одна задача = один коміт.

**Не відповідати самому на власні уточнювальні питання.** Якщо задано
питання — чекати відповіді.

## 1. Виміри замість вражень

**Перед тим, як сказати «виглядає добре», зміряти.** Скріншот цілої
сторінки сильно зменшений — кегль на ньому виглядає дрібнішим, ніж є.
Діагностувати типографіку по таких скрінах заборонено.

Мінімальний набір вимірів після візуальної правки:

```js
// у консолі сторінки
const el = document.querySelector('SELECTOR');
const r = el.getBoundingClientRect();
const cs = getComputedStyle(el);
({ w: r.width, h: r.height, fs: cs.fontSize, lh: cs.lineHeight,
   pt: cs.paddingTop, pb: cs.paddingBottom });
```

**Довжина рядка — обовʼязковий вимір для будь-якого текстового блоку.**
Ціль 60–75 символів. Порахувати: `ширина_колонки / (кегль * 0.5)`.
Менше 45 — помилка, текст рветься на обрубки. Більше 90 — око губить рядок.

**Співвідношення контенту до паддінгів у секції.** Якщо паддінги
складають більше третини висоти секції — це діра, а не повітря.

## 2. Пастки середовища

- **У Chrome-профілі Claude Code системно увімкнений
  `prefers-reduced-motion: reduce`.** Будь-яка перевірка анімації через
  браузер за замовчуванням покаже статику. Це не баг сайту.
- `document.visibilityState === "hidden"` у фонових вкладках тротлить
  rAF і анімації.
- **`npm run dev` без зупинки попереднього тихо займає наступний порт.**
  За сесію накопичувалось пʼять серверів на 4321–4325, і перевірявся
  не той. Перед запуском — перевірити, що працює на 4321.
- Кирилиця в PowerShell бʼється. `git diff > temp\diff.txt` і відкривати
  у VS Code.

## 3. Правила верстки (не обговорюються)

**Український перенос:**
```css
overflow-wrap: break-word;
word-break: normal;
hyphens: manual;
```
НІКОЛИ `word-break: anywhere`. НІКОЛИ `hyphens: auto`.

**Переповнення:**
`overflow-x: clip`, ніколи `hidden` — `hidden` робить елемент
scroll-контейнером і ламає `position: sticky`. `overflow-y` не задавати
взагалі. Фолбек `@supports not (overflow: clip)` на `hidden` для
Safari <16, де sticky однаково не працює.

**Грід:** `min-width: 0` на всіх дітях. Без цього `min-width: auto`
дозволяє дитині відмовитись стискатись нижче свого контенту.

**Анімація:** тільки `transform` і `opacity`. Ніякого `transition: all`.
Ніякого `filter` / `box-shadow` / `drop-shadow` на анімованих
елементах — вони не composited.

`prefers-reduced-motion` продумувати в задумі, не додавати наприкінці.

**Вирівнювання структурне, гридом.** Ніяких емпіричних `calc()` з `vw` —
вони розсипаються при зміні будь-якого `clamp()` вище по каскаду.

**Каскадні зсуви через `margin`, не через `transform`.**

**Hover не змінює висоту і не зсуває сусідні елементи.**

**Розміри тексту — `clamp()`, не фіксовані px.** Фіксований 96px на H2
працює на 1440 і ламається на 1024.

## 4. Дизайн-система

Токени: `--accent-500`, `--info`, `--text-muted`, `--text-2`, `--border`,
`--surface-2`, `--bg`, `--font-display`, `--font-mono`, `--font-body`.

Manrope (body), JetBrains Mono (технічне).

**Кольори і шрифти тільки з наявних токенів. Нових залежностей не додавати.**

Патерн секції:
```html
<section class="{name} section-shell">
```

## 6. Формат кейсів

`src/content/cases/*.md`. **Тіла markdown немає** — весь текст у
структурованому frontmatter, `CaseStudy.astro` рендерить поля.

Обовʼязкові поля: `title, engine, duration, summary, caseNumber, order,
client, url, domain, category, heroHeadingLine1/2, heroLog, heroStats,
context{heading,body}, whatIRun{heading,body,topology},
reliability{metrics, terminalTitle, terminalStatus, terminalLines},
result{heading,body,bullets}`.

Опційні: `seoTitle, seoDescription, status, since, until, productHistory,
proofs, nextSignal, outcome, context.quote, result.testimonials`.

`outcome` рендериться **тільки** при `status: archived`. Для живих кейсів
усе йде в `result.body`.

`heroStats.label` і `topology.key` — короткі англійські теги
(`lifetime`, `catalog`, `portfolio`).

`heroLog` — префікс `$ tail -f {slug}.service →`.

Поле називається `headingEm`, не `headingLine1Em`.

## 7. Деплой

Власний VPS з Apache. `deploy.yml` → self-hosted GitHub Actions runner на
тому ж VPS → `npm ci && npm run build` → `rsync -avzr --delete dist/ $DEPLOY_PATH`.
`DEPLOY_PATH` — секрет GitHub Actions.

**Обережно: `rsync --delete` видаляє на сервері все, чого немає в `dist/`.**

`public/.htaccess` містить рівно один рядок:
`ErrorDocument 404 /404.html`. Не додавати туди нічого без окремого рішення.
