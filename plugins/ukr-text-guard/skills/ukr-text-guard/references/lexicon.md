# Словник редактора

Зміст: 1. Заміни ШІ-кліше · 2. Синонімічні ряди · 3. Питомо українські звороти й фразеологізми · 4. Діалектизми · 5. Слова для розширення запасу

Принцип: заміна має бути **точнішою**, а не просто іншою. Якщо кліше можна викреслити без втрати змісту — викреслюй.

---

## 1. Заміни ШІ-кліше

| Кліше | Що робити |
|---|---|
| Варто зазначити, що… / Важливо підкреслити… | Викреслити й одразу сказати суть |
| У сучасному світі / у наш час | Конкретний час і місце: «Цієї осені…», «Відколи почалися відключення…» |
| відіграє ключову роль | від якого залежить…, на якому тримається…, без чого не обійтися |
| відкриває нові можливості | дає змогу…, дозволяє… (і назвати, що саме) |
| широкий спектр послуг | перелічити 2–3 конкретні послуги |
| комплексний підхід | описати, які саме кроки поєднано |
| індивідуальний підхід | приклад: «підлаштуємо графік під ваші зміни» |
| інноваційне рішення | що нового і для кого |
| Таким чином / Отже, підсумовуючи | Тож…, Зрештою…, Виходить, що… — або просто висновок без маркера |
| Це не просто X — це Y | Сказати Y прямо, з фактом |
| Давайте розберемося / Зануримося | Розберімося (наказовий спосіб 1-ї особи мн.) — або почати одразу зі змісту |
| є невід'ємною частиною | без чого не буває…, що давно стало звичним |
| на сьогоднішній день | сьогодні, нині, наразі |
| з метою покращення | щоб поліпшити |
| здійснювати контроль | контролювати, наглядати |
| проводити аналіз | аналізувати, розбирати |
| надавати послуги | робити, виконувати, пропонувати |
| у разі виникнення питань | якщо щось незрозуміло / якщо маєте питання |

## 2. Синонімічні ряди (для слів, які ШІ повторює найчастіше)

**важливий** — вагомий, суттєвий, істотний, помітний, визначальний, нагальний, пекучий (про проблему), першорядний, неабиякий
**великий** — значний, чималий, солідний, величезний, неосяжний, здоровенний (розм.), неабиякий, добрячий (розм.)
**багато** — чимало, безліч, сила-силенна, до біса (розм.), вдосталь, рясно, гора (розм.), не злічити
**мало** — обмаль, трохи, дещиця, крихта, кіт наплакав (фразеол.), жменька
**дуже** — надзвичайно, вельми, неабияк, страшенно (розм.), геть, украй, навдивовижу, до краю
**робити** — виконувати, створювати, чинити, виготовляти, майструвати, лаштувати, братися за, давати раду
**говорити/казати** — мовити, промовляти, зауважувати, наголошувати, пояснювати, розповідати, ділитися, прохопитися (ненароком), бовкнути (розм.)
**допомагати** — підсобляти (розм.), сприяти, підтримувати, ставати в пригоді, виручати, рятувати, підставляти плече
**показувати** — демонструвати, унаочнювати, виявляти, засвідчувати, розкривати, свідчити про
**використовувати** — застосовувати, послуговуватися, вдаватися до, користуватися, залучати, пускати в хід
**можливість** — змога, нагода, шанс, спромога, умова, перспектива
**проблема** — клопіт, морока (розм.), халепа (розм.), завада, перешкода, заковика, негаразд, біда
**швидко** — хутко, прудко, миттю, вмить, чимдуж, притьмом, духом (розм.), не гаючись, за лічені хвилини
**повільно** — поволі, помалу, спроквола, неквапом, ледве-ледве
**гарний/добрий** — чудовий, ладний, пристойний, вдалий, охайний, довершений, путящий (розм.), ловкий (розм.)
**новий** — свіжий, недавній, щойно створений, сучасний, небачений, оновлений
**почати** — розпочати, взятися, заходитися, приступити, завести, узятися за діло
**закінчити** — завершити, довершити, докінчити, покінчити з, упоратися, звести кінці з кінцями (про гроші)
**думати** — міркувати, розмірковувати, гадати, вважати, зважувати, мізкувати (розм.), сушити голову
**зараз** — нині, тепер, наразі, саме тепер, у цю хвилину
**також** — теж, так само, до того ж, ба більше, крім того, до всього, окрім цього
**тому** — тож, отже, через те, відтак, з цієї причини, ось чому
**але** — проте, однак, зате, втім, та, одначе, щоправда
**клієнт** — замовник, покупець, відвідувач, користувач (залежно від контексту — не синоніми, а точніші слова)

## 4. Діалектизми

**Правила вживання:**
- лише в літературно-розважальному стилі (або в заголовку чи ліді змішаного жанру);
- не частіше ніж 1 на 200–400 слів;
- значення має бути зрозуміле з контексту, інакше — коротке пояснення;
- обирай регіон, що пасує тематиці й аудиторії тексту; не змішуй гуцульське з поліським в одному абзаці без причини.
