# ukr-text-guard

Маркетплейс плагінів `ifurman` для Claude (Claude Code, Claude Desktop, claude.ai). Основний блок — агенти для роботи з українськими текстами: детекція написаного штучним інтелектом і редагування живою мовою.

## Підключення

```bash
/plugin marketplace add ifurmandev/ukr-text-guard
/plugin install ukr-text-guard@ifurman
```

Далі плагіни видно в `/plugin`. Для команди чи кількох машин маркетплейс можна прописати в `.claude/settings.json`:

```json
{
  "extraKnownMarketplaces": {
    "ifurman": {
      "source": { "source": "github", "repo": "ifurmandev/ukr-text-guard" }
    }
  },
  "enabledPlugins": { "ukr-text-guard@ifurman": true }
}
```

## Плагіни

| Плагін | Що робить |
|---|---|
| `ukr-text-guard` | **2 в 1** — детектор + редактор + повний цикл «перевір → перепиши → заміряй знову» |
| `ukr-text-detector` | тільки аудит: індекс ознак ШІ 0–100, докази, гарячі точки, вердикт |
| `ukr-text-editor` | тільки редагування за шістьма правилами живої української |
| `ifurman-frontend-review` | правила верстки, типографіки й протокол комітів для сайту ifurman.dev (Astro 5 + Tailwind 4) |

Ставте `ukr-text-guard` **або** пару `detector` + `editor` — разом вони дублюють один одного.

## Що ловить детектор

- лексика: кліше, рекламні епітети, канцелярит, кальки з російської та англійської;
- ритм і структура: рівні речення й абзаци, симетричні списки, пасивні початки, «Мітка: Опис», двомовні глоси;
- сліди чату та шаблонів («Нижче наведено», `[назва компанії]`, «як мовна модель»);
- обфускацію: невидимі символи, латинські двійники кириличних літер — +25 до індексу;
- «інженерну людяність» (ШІ, промптований під людину) — за надмірностями прийому;
- SEO-переспам і ознаки на рівні цілого сайту;
- гарячі точки — абзаци з найбільшою густотою ознак у змішаних текстах.

### Чесна межа

Індекс — евристика, а не доказ авторства. Добре промптований ШІ-текст без кліше і з вигаданою конкретикою дає близько 10/100: його видають лише перевірка фактів і якісний аналіз. Не ставте вердикт людині за самим індексом.

## Шість правил редактора

1. Складносурядні й складнопідрядні речення впереміш із простими.
2. Дієприслівники обох видів; дія зворота належить підметові головного речення.
3. Відокремлені обставини у складних реченнях.
4. Стиль під завдання: літературно-розважальний (з діалектизмами), діловий, технічний.
5. Максимальний словниковий запас — але терміни й назви повторюються, а не урізноманітнюються.
6. Багатство відтінків: фразеологізми, вставні слова, безсполучникові речення, парцеляція, інверсія — за таблицею дозування.

python3 plugins/ukr-text-guard/skills/ukr-text-guard/scripts/analyze.py текст.txt --json

3 з 3 людських зразків мають 150 слів і більше, тож висновок для людських текстів не позначено як невизначений. Зразки походять від трьох авторів: Івана Франка, Михайла Коцюбинського і Верховної Ради України. Усі три тексти написані до 2023 року, походження кожного записано в `evals/samples/SOURCES.md`.

Покриті жанри: художня проза (два оповідання, класика) і юридичні документи (початок Конституції України 1996 року). Не покриті жанри: ділові листи й пошта, статті й блоги. Для них не знайшлося вільного джерела сучасного тексту з доведеною датою до появи генеративного ШІ, а власних текстів автора плагіна в наборі поки немає. Тобто набір складається з класичних і офіційних текстів і не доводить, що детектор безпечний для інших видів сучасного тексту. Індекс 19 у Конституції вищий за 15, але в межах смуги 25: для формального тексту це найближче до межі. Індекс — евристика ознак ШІ, а не доказ авторства; докладніше — у розділі [Чесна межа](#чесна-межа).

```bash
bash evals/run.sh
```
